# china-web-lab

## 简介

**china-web-lab** 是一个用于归档和发布多个独立 HTML 页面的仓库。  
本仓库不针对任何单个域名或具体网站，仅作为一批静态页面的集中存放与展示空间。

这些页面可能涵盖工具、信息展示、实验性交互等不同用途，每个页面独立运行，彼此之间没有依赖关系。

## 目录结构

```
china-web-lab/
├── pages/           # 存放所有独立 HTML 页面
│   ├── example-1/
│   │   └── index.html
│   ├── example-2/
│   │   └── index.html
│   └── ...
├── assets/          # 页面共享的资源文件（如有）
│   ├── styles/
│   ├── scripts/
│   └── images/
├── LICENSE
└── README.md
```

- `pages/`：每个子文件夹对应一个独立页面，内含 `index.html` 及其他必要资源。
- `assets/`：可选，存放多个页面可能共同使用的样式、脚本或图片。

## 页面归档说明

- 每个页面均为自包含的 HTML 文件，可直接在浏览器中打开运行。
- 页面之间不共享状态或数据，彼此完全独立。
- 页面可能包含外部资源（如 CDN 引用的库文件），请确保网络可用性。
- 部分页面可能为实验性质，不保证长期可用或兼容所有浏览器。

## 维护说明

- 本仓库由维护者不定期更新，新增或移除页面均会通过 commit 记录。
- 欢迎通过 Issue 提交建议或报告问题，但请注意本仓库不提供技术支持或功能承诺。
- 如需贡献新页面，请遵循以下原则：
  - 每个页面独立放在 `pages/` 下的单独文件夹中。
  - 页面内不应包含指向外部特定服务或营销链接。
  - 保持代码简洁、可读，不引入恶意或跟踪代码。
